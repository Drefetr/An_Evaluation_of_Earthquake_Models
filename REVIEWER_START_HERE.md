# Scientific completion: reviewer guidance

This scientific-completion edition incorporates the accepted bounded follow-up programme. The baseline monograph remains immutable in its original directory. S04B numerical and visual reviews are accepted for their declared scope. Fresh isolated production validation and the final delivery manifest identify the delivered artifact; baseline production evidence is archived outside this payload.

Accepted new results are distinguished from historical checkpoints in the manuscript. S01 uses preserved resolved statistics plus authorized missing-only recovery under oracle calibration. S04 synthetic controls retain every prescribed history and all negative outcomes. Independent numerical validation is sampled where declared; an accepted result is not a claim of independent raw replay for every calculation.

The source ledger binds displayed values to bundled aggregate authorities. It checks the enumerated claims, not exhaustive scientific correctness or causal interpretation. Current claim receipts do not by themselves establish release acceptance.

Acceptance receipts state their individual validation coverage. Some evidence references identify private research archives outside this publication package. The bundled aggregate authorities and claim ledger support document review; this package does not include every numerical engine or raw catalogue needed to reproduce the experiments.

The preserved `provenance/historical_v4_source_index.json` describes an earlier archive's layout and availability. Its `included_path` and `availability_status` fields are historical metadata, not an inventory of this package.

## Verification

From this package directory:

```powershell
python -B -m unittest discover -s tests -p test_verify_claims.py
python -B scripts/verify_claims.py
python -B scripts/build_paper.py --output build/my_isolated_check
```

Tectonic 0.17.0 and its available TeX resources are required. Use a fresh output directory. The default build does not promote the PDF. Raw catalogue rows, histories, caches and private fitted vectors remain outside the review payload. Rebuilding the document is distinct from rerunning numerical experiments. The scientific follow-up performs explicitly authorized computations; it does not activate operational forecasts.
