# Methodological revision evidence

The scalar comparator campaign is a new computation on the 80 saved S04B histories. refitted_floor/result.json contains all cases and the 20 procedure summaries; refitted_floor_summary.json adds the score-component averages used by the paper. Reproduce or check these with experiments/s04b_refitted_floor/README.md.

synthetic_diagnostics.json reaggregates original generation counters and all selected fit vectors. moments.json and stability.json are source-pinned analytic/scalar diagnostics, not new simulation experiments. Their executables are in experiments/methodological_audit/.

internal_reviews/ and refitted_floor/*review* retain distinct internal source and output audits. Private original paths are historical metadata. The supervision scripts and build/helper records in refitted_floor/ are exact execution evidence for the original Windows workspace, not portable entry points; use the experiment README to run elsewhere. The initial attempt is retained as failed: compilation succeeded, but an owned compiler helper prevented the quiescence gate. No history was scored before that stop. After identity-checked cleanup, the continuation reused the exact build and executed the fixed pilot and remaining cases.

The original authorities, histories, fitted inhibition states and selection gates are unchanged. The control refits only the uninhibited background intercept; it does not demonstrate joint nuisance fitting, parameter recovery, prospective confirmation or external peer review.
