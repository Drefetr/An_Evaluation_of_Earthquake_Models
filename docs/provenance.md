# Public provenance

This public repository combines preserved historical numerical modules and source identities with the unified monograph, later Stage 2 studies, S04B matched-law controls, companion guide, and site. The [change history](changes.md) dates the major editions. Original scientific findings are distinguished from publication adaptations and later completed studies.

## Current files and historical identities

`MANIFEST.json` records current public payload membership and bytes. [Extraction records](../provenance/extraction_manifest.json) identify preserved source pins and declared public variants. [Historical v4 digests](../provenance/historical_v4_archive_digests.json), [verification](../provenance/historical_v4_verification.json), and [source index](../provenance/historical_v4_source_index.json) describe the earlier sealed archive; their paths and availability labels are historical metadata rather than promises that those files are in this checkout.

The [historical archive index](../provenance/historical_archive.json) identifies preparation receipts, release-control state, and process telemetry retired from the current working tree. Their baseline Git identities remain available without presenting them as current project state. Current bounded checks are described in [validation documentation](../validation/README.md).

Historical numerical Python modules retain their original identities. Public adaptations are recorded separately in [public_adaptations.json](../provenance/public_adaptations.json). The exact historical observed protocol is retained in [historical_observed_protocol.json](../provenance/historical_observed_protocol.json); the public protocol binds its declared launcher variants. New wrappers or portability fixes must not silently overwrite the historical scientific source identities.

## Scientific evidence and public variants

The manuscript ledger binds enumerated displayed values to bundled authorities; the separate source inventory retains additional numerical provenance. The [authority index](../validation/authority_manifest.json) maps bundled sources to their historical identities. Some sources preserve historical references to unavailable archives. A retained hash establishes identity, not public availability, scientific correctness, or a completed replay.

The [readable authority index](../provenance/authority_index.json) maps original source names to current canonical paths. [Public authority variants](../provenance/public_authority_variants.json) distinguish current portable hashes from historical hashes retained inside original source records. [Stage 2 recovery identities](../provenance/stage2_source_recovery.json) record the missing dependencies recovered for the supported code surface.

Public variants can replace machine-specific roots with portable identifiers while preserving original and transformed digests. Such changes require coordinated source hashes, path mappings, exact documentary locators, dependent bindings, and receipts. Scientific values, observation rules, fitting contracts, and inference scope must remain explicit. See [publication privacy](privacy.md) and the [data guide](data.md).

Third-party event records, the earlier third-party manuscript PDF, complete raw result/cache trees, dependencies, and private investigation transcripts are excluded. Selected project-derived aggregates and scientifically relevant validation evidence remain. Work orchestration is distinguished from numerical controls and computational evidence; the latter are not discarded because a filename contains "control" or "review".

The repository is publicly accessible at [Drefetr/InhibitoryEarthquakeModels](https://github.com/Drefetr/InhibitoryEarthquakeModels). Older prepublication privacy records describe their dated scope and must not be read as a current visibility, workflow, or credential guarantee.
